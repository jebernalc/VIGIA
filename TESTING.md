Ejecutar `cd vigia && python -m pytest tests -q`. El test crea un video `testsrc` con FFmpeg y comprueba carga, hash original, trabajo asíncrono, JPEG auténtico, respuesta honesta ante búsqueda de personas, clip y hash, informe con fuente y aislamiento de cámaras, grabaciones, fotogramas, clips, casos e informe entre dos organizaciones. Comprueba también que cerrar sesión revoca el token.

Una segunda prueba simula las respuestas de Supabase Auth y PostgREST: registro, creación de organización maestra, edición de su nombre, separación de dos cuentas y revocación de sesión. Se verificó en el proyecto remoto que las dos tablas `vigia_*` existen, tienen RLS habilitado y políticas específicas; estaban vacías en la comprobación. No se han creado usuarios reales ni enviado correos. El asesor de seguridad existente del proyecto señala que la protección frente a contraseñas filtradas está deshabilitada; no se cambió esta configuración compartida.
